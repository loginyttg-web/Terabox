# TeraBox Pro Bot

TeraBox resolver API and Telegram bot with Railway, Render, Docker, and Heroku deployment support. The application source is in [`terabox-project/`](terabox-project/).

[![Deploy to Heroku](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/loginyttg-web/Terabox/tree/main)

## Deployment

- **Heroku:** see [`HEROKU.md`](HEROKU.md) for one-click, GitHub, and CLI setup.
- **Railway / Render / Docker:** see [`terabox-project/DEPLOYMENT.md`](terabox-project/DEPLOYMENT.md).
- **Application docs:** see [`terabox-project/README.md`](terabox-project/README.md).

The Heroku setup uses the container stack and includes Node.js 22 plus `zip`, while leaving the existing Railway configuration unchanged.
